# ExamenAltLinux
Шпаргалка по демонстрационному экзамену специальности 09.02.06 «Сетевое и системное администрирование» составлена на основе предоставленного практикума. Ниже приведена подробная справка по основным модулям, их назначению и ключевым командам конфигурации.
Модуль 1. Настройка сетевой инфраструктурыЧто делает модуль: Отвечает за проектирование, адресацию, базовую настройку оборудования, маршрутизацию, коммутацию (VLAN) и предоставление базовых сетевых сервисов (DHCP, DNS, туннелирование) для связи центрального офиса (HQ) и филиала (BR).
1. Базовая настройка и управление именами (ОС Альт и EcoRouter)ОС «Альт» (Серверы / Рабочая станция):hostnamectl set-hostname <hostname>.<domain>; exec bash — изменяет имя машины на полное доменное имя (FQDN) и перезапускает командную оболочку, чтобы изменения сразу отобразились в консоли.EcoRouterOS (Маршрутизаторы HQ-RTR, BR-RTR):enable — переход в привилегированный режим управления.configure terminal — переход в режим глобального конфигурирования устройства.hostname <name> — задает имя устройства.ip domain-name <domain> — привязывает устройство к указанному домену.write memory — сохраняет текущую конфигурацию в энергонезависимую память (аналог copy run start).
2. Настройка сетевых интерфейсов и IPv4ОС «Альт» (через подсистему etcnet):ip a / ip r — просмотр текущих IP-адресов интерфейсов и таблицы маршрутизации.vim /etc/net/ifaces/<ИМЯ_ИНТЕРФЕЙСА>/options — файл базовых опций интерфейса. Для статики прописывается: BOOTPROTO=static и TYPE=eth. Для ISP (автоматическое получение): BOOTPROTO=dhcp.vim /etc/net/ifaces/<ИМЯ_ИНТЕРФЕЙСА>/ipv4address — файл для указания статического IP (формат: 192.168.100.1/26).vim /etc/net/ifaces/<ИМЯ_ИНТЕРФЕЙСА>/ipv4route — статические маршруты (например, шлюз по умолчанию: default via 192.168.100.62).systemctl restart network — перезапуск сетевой службы для применения всех изменений.EcoRouterOS (L3 интерфейсы и привязка к портам):show port brief — просмотр физического состояния сетевых портов устройства.interface <ИМЯ> -> ip address <IP>/<Префикс> — создание логического L3-интерфейса и назначение на него адреса.port <ИМЯ_ПОРТА> -> service-instance <ИМЯ> -> encapsulation untagged -> connect ip interface <ИМЯ_ИНТЕРФЕЙСА> — связывает физический L2-порт с созданным логическим L3-интерфейсом для обработки нетегированного трафика.ip route 0.0.0.0/0 <ШЛЮЗ> — добавление статического маршрута по умолчанию (выход в интернет).show ip interface brief — проверка состояния и IP-адресов всех интерфейсов.
3. Настройка NAT (Трансляция адресов на ISP)net.ipv4.ip_forward = 1 (в файле /etc/net/sysctl.conf) — включает режим маршрутизации (пересылки пакетов между интерфейсами) на Linux-сервере провайдера.iptables –t nat –A POSTROUTING –o <ВНЕШНИЙ_ИНТЕРФЕЙС> –j MASQUERADE — добавляет правило динамической трансляции (маскарадинга) в таблицу NAT для всех исходящих пакетов через внешний интерфейс.iptables-save >> /etc/sysconfig/iptables — сохраняет правила брандмауэра Linux.systemctl enable --now iptables — активирует службу iptables и добавляет её в автозагрузку.
4. Создание локальных пользователейОС «Альт»:useradd sshuser -u 1010 — создание пользователя с фиксированным числовым идентификатором (UID).passwd sshuser — установка или смена пароля учетной записи.gpasswd -a sshuser wheel — добавление пользователя в группу администраторов wheel.visudo — редактирование прав доступа. Необходимо раскомментировать строку: WHEEL_USERS ALL=(ALL:ALL) NOPASSWD: ALL для работы sudo без ввода пароля.EcoRouterOS:username net_admin -> password <ПАРОЛЬ> -> role admin — создание локального пользователя, назначение пароля и выдача максимальной роли администратора (admin).show users localdb — просмотр созданных локальных пользователей и их ролей.
5. Коммутация на виртуальном коммутаторе (HQ-SW на базе Open vSwitch)ovs-vsctl add-br SW — создает новый виртуальный программный коммутатор (мост) с именем "SW".ovs-vsctl add-port SW ens3 trunk=100,200,999 — добавляет физический интерфейс в качестве магистрального (Trunk), разрешая прохождение тегированных кадров указанных VLAN (100, 200, 999).ovs-vsctl add-port SW ens4 tag=100 — добавляет интерфейс доступа (Access) и вешает на него тег VLAN 100.ovs-vsctl show — отображает текущую архитектуру коммутатора OVS и распределение портов по VLAN.Модуль 2. Организация сетевого администрирования операционных системЧто делает модуль: Отвечает за развертывание внутренних сервисов предприятия, автоматизацию управления конфигурациями, контейнеризацию приложений и облачную оркестрацию на базе отечественных ИТ-платформ.Включает следующие крупные технологические блоки согласно плану экзамена:Инфраструктурные сервисы: Настройка сетевых хранилищ, синхронизация точного времени через службу chrony, развертывание корпоративного DNS-сервера.Автоматизация (IaC): Настройка среды Ansible для автоматического развертывания конфигураций и управления целевыми хостами без ручного вмешательства.Контейнеризация и Веб-среда: Развертывание Docker-контейнеров, запуск СДО Moodle, конфигурирование веб-сервера Nginx в роли Reverse Proxy (обратного прокси) с пробросом/трансляцией портов.Виртуализация и CLI-управление: Развертывание и базовая подготовка платформы Кибер Инфраструктура, управление сущностями вычислительного кластера (сети, образы ОС, виртуальные машины) через портал самообслуживания и консольные утилиты OpenStack CLI.
